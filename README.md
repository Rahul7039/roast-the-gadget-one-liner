This entry roasts the washing machine: it plays a triumphant little jingle
when it finishes a wash — even when the load was a single sock. One job, and
it still wants applause. The program validates the line against the
competition gate (one line, 1–200 characters, not only whitespace) and writes
it to `/output/entry.txt` for the judge.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Python 3, standard library only — nothing to install.
